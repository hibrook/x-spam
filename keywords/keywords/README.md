# x-spam keywords 整理版

用于 `hibrook/x-spam/keywords/`。

本次来源：用户提供的关键词截图，截图可见约 330 条；页面显示总量 635 条，因此本目录只整理了截图可见部分。

## 文件怎么用

### `absolute.txt`
直接屏蔽。只放高置信度、导流/色情垃圾特征较强的词和短语。

### `highrisk.txt`
只参与评分，不建议单词命中就直接屏蔽。这里放容易出现在引用、讨论、调侃中的词。

### `patterns.txt`
正则模板。用于识别组合结构，例如：
- 同城 + 上门/空降/私约/约炮
- 主页 + 福利/领取
- 线下 + 报名/可约
- “只进入身体……不进入生活”一类模板
- 你此前发现的 Emoji/时间戳模板

### `whitelist.txt`
正常用户表达。只用于降低误杀风险，不覆盖绝对词和强正则。

### `trusted_accounts.txt`
官方/可信账号 Handle 白名单。只按 `@handle` 判断。

### `review_only.txt`
人工审核区，**当前脚本不会读取**。用于存放过于通用、疑似人名/站名或和“黄推”关系不够直接的词，避免一次性加入造成误杀。

## 放置位置

把本目录内的这些文件上传到：

`hibrook/x-spam/keywords/`

其中 `review_only.txt` 可以一起保存，但当前脚本不会主动下载它。
